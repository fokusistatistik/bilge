# Bilge (Scientific Statistics and Literature Development Instrument)

Bilge is a next-generation academic analysis platform that acts as an AI-powered mentor for researchers.

## Features (v1.0)
- **Glass Box Analysis**: Step-by-step statistical guidance.
- **Academic Trustworthiness**: APA 7 reporting and strict assumption checking.
- **Credit System**: Internal economy for computational analysis.
- **Interactive Chat**: Widget-based conversation flow.

## Tech Stack
- Next.js 14 (App Router)
- TypeScript
- Tailwind CSS / ShadCN UI
- Zustand (State Management)
- Lucide React (Icons)

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run the development server:
   ```bash
   npm run dev
   ```

3. Open [http://localhost:3000](http://localhost:3000)

## Demo Flow
1. Click "Get Started" on the Landing Page.
2. Click "Continue with Google" on the Login Page (Mocked).
3. If this is your first time, complete the "Profile Onboarding" modal.
4. In the Dashboard, type "upload data" or similar to trigger the demo analysis flow.
5. Follow the widget interactions (Confirm Variables -> Select Method -> Confirm Credits).
